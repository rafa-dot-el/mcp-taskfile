#+title: mcp-taskfile
#+options: toc:nil num:nil

An MCP server that turns the public tasks of a [[https://taskfile.dev][Taskfile]] into MCP tools, so an agent calls =test=, =lint= or =build= instead of guessing shell commands. The tool list follows the Taskfile: edit it, and connected clients see the change.

Version 0.1.0. Transport: stdio. Requires Nix.

* Example

Given this =Taskfile.yml=:

#+begin_src yaml :eval never-export
version: "3"
tasks:
  test:
    desc: Run the unit tests
    cmds: [go test ./...]
  deploy:
    desc: Deploy to an environment
    requires: { vars: [ENV] }
    cmds: ["./deploy.sh {{.ENV}} {{.CLI_ARGS}}"]
  ci:build:
    desc: Build the binary
    cmds: [go build ./...]
  fmt:
    cmds: [gofmt -w .]
#+end_src

the server exposes three tools: =test=, =deploy= (parameters =ENV= and =cli_args=) and =ci_build=. =fmt= has no =desc=, so it stays hidden.

* Quick start

Add the server to your MCP client (stdio), pointing =--dir= at the project:

#+begin_src json :eval never-export
{
  "mcpServers": {
    "taskfile": {
      "command": "nix",
      "args": ["run", "github:rafa-dot-el/mcp-taskfile", "--", "--dir", "/path/to/project"]
    }
  }
}
#+end_src

Append a tag to pin a release: =github:rafa-dot-el/mcp-taskfile/v0.1.0=.

* Prebuilt binaries

Each [[https://github.com/rafa-dot-el/mcp-taskfile/releases][GitHub Release]] carries one archive per platform (=.zip= on Windows, =.tar.gz= elsewhere) and =SHA256SUMS=. Verify before running:

#+begin_src bash :eval never-export
sha256sum -c --ignore-missing SHA256SUMS
gh attestation verify mcp-taskfile_0.1.0_linux_amd64.tar.gz -R rafa-dot-el/mcp-taskfile
#+end_src

| OS      | amd64 | arm64 |
|---------+-------+-------|
| Linux   | yes   | yes   |
| macOS   | yes   | yes   |
| Windows | yes   | yes   |
| FreeBSD | yes   | yes   |
| OpenBSD | yes   | no    |
| NetBSD  | yes   | no    |

Every binary is a static pure-Go build (=CGO_ENABLED=0=). The test suite runs on Linux only; the other platforms are cross-compiled and checked for the executable format, not executed in CI.

* How tasks become tools

| Taskfile                           | MCP tool                                               |
|------------------------------------+--------------------------------------------------------|
| task with a =desc=                 | one tool, described by the =desc=                      |
| task without =desc=, or =internal= | not exposed                                            |
| =requires: vars: [NAME]=           | string parameter =NAME= (Task enforces it)             |
| every tool                         | optional string parameter =cli_args= (={{.CLI_ARGS}}=) |
| =ci:build=                         | tool =ci_build=                                        |

- *Output:* a successful call returns the task's stdout, followed by a =[stderr]= section when the task wrote to stderr. A failing task returns a tool error with the exit status and the same output.
- *Reload:* the Taskfile and every included Taskfile are watched. A broken edit keeps the last good tool set.
- *Name clashes:* =a:b= and =a_b= both map to =a_b=. The first task in task-list order wins (root tasks before namespaced ones); the other is logged as a warning.
- *Timeout:* each call is limited by =--task-timeout=. On expiry the task is killed and the tool returns an error naming the timeout.

* Options

| Flag / variable           | Meaning                                                        |
|---------------------------+----------------------------------------------------------------|
| =--dir PATH=              | directory holding the Taskfile (default: current directory)    |
| =--task-timeout DURATION= | per-call limit, e.g. =90s=, =10m= (default =5m=, =0= disables) |
| =--version=               | print the version and exit                                     |
| =MCP_TASKFILE_LOG_LEVEL=  | =trace=, =debug=, =info=, =warn=, =error=, =crit=              |

* Use from another Nix flake

=package.nix= is a plain =callPackage= file. Import the repository as source (=flake = false=) and build it with your own =pkgs=: one extra lock entry, no second nixpkgs. Your nixpkgs must provide =go_1_26=.

#+begin_src nix :eval never-export
inputs.mcp-taskfile = {
  url = "github:rafa-dot-el/mcp-taskfile";
  flake = false;
};

# where pkgs is your nixpkgs:
mcp-taskfile = pkgs.callPackage "${inputs.mcp-taskfile}/package.nix" { };
#+end_src

* Security

The server runs Taskfile commands with the privileges of the user that starts it. Point =--dir= only at projects whose Taskfile you trust, and do not expose the stdio transport to untrusted clients. To report a vulnerability, see [[file:SECURITY.md][SECURITY.md]].
